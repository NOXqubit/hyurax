Privacidade e cookies

Versão 1 · 26 de setembro de 2026 · vale para este site e para o programa Hyurax

Resumo: este site não usa cookies, não tem rastreamento, não tem anúncios e não carrega nada de outra empresa. O programa não envia dados de uso para o projeto. Não pedimos, não recebemos e não guardamos dados pessoais seus.

1. Quem somos

O Hyurax é um projeto de software livre, feito por um desenvolvedor independente. Não é empresa e não vende nada. O código está aberto no GitHub, e qualquer pessoa pode conferir o que está escrito aqui.

2. O site

  • Cookies: nenhum. O site não cria cookie nenhum, nem de "sessão", nem de estatística, nem de publicidade.
  • Armazenamento no seu navegador: duas anotações pequenas, no localStorage do seu próprio navegador: o idioma que você escolheu e o fato de você já ter visto o aviso de privacidade. Elas servem só para o site lembrar a sua escolha; não saem do seu aparelho, e você apaga as duas limpando os dados do site no navegador.
  • Terceiros: nenhum. As fontes, os scripts e as imagens vêm deste mesmo site. Não usamos Google Fonts, Google Analytics, redes sociais embutidas, pixels de publicidade nem nada parecido. Por isso nenhum dado da sua visita vai para outra empresa.
  • Hospedagem: o site é servido pelo GitHub Pages. Como qualquer servidor, o GitHub recebe o endereço IP e o navegador de quem acessa, e trata isso pela política de privacidade dele. O projeto não tem acesso a esses registros.
  • Links para fora: os botões de download e o código levam ao GitHub. Ao clicar, você passa a estar no site do GitHub, com as regras dele.

3. O programa

  • Os dados do programa (a cadeia, a carteira cifrada com a sua senha, o histórico do ULTRAX e os ajustes) ficam na pasta %APPDATA%\Hyurax do seu computador. O projeto não recebe esses dados.
  • O programa conversa com outros nós da rede Hyurax, por conexão cifrada. Como em toda rede par a par, os nós com que você se conecta veem o seu endereço IP.
  • Ele baixa a lista pública de nós semente do repositório do projeto no GitHub.
  • Ele consulta a api.coingecko.com para mostrar preços de criptomoedas só se você ligar o painel "Mercado".
  • Não há telemetria, estatística de uso, relatório de erro automático nem anúncio.
  • A cadeia é pública: endereços e valores das transações ficam visíveis para qualquer nó, para sempre. Não coloque informação pessoal na cadeia.

4. Seus direitos (LGPD)

A Lei Geral de Proteção de Dados (Lei 13.709/2018) garante a você, entre outros, os direitos de saber que dados pessoais seus são tratados, de acessar, corrigir e apagar. Como o projeto não coleta nem guarda dados pessoais seus, não há cadastro para consultar ou apagar do nosso lado. O que existe está no seu próprio aparelho, sob seu controle:

  • no navegador, apague os dados deste site para remover as duas anotações de preferência;
  • no computador, feche o programa e apague a pasta %APPDATA%\Hyurax para remover tudo o que ele guardou. Isso apaga também a carteira: guarde uma cópia antes, se quiser.

5. Segurança

O site traz uma política de segurança de conteúdo que só deixa rodar código deste próprio site. Falhas de segurança, no site ou no programa, se relatam pelo caminho descrito em SECURITY.md, também listado em /.well-known/security.txt.

6. Mudanças

Se esta política mudar, a versão e a data no topo mudam junto, e a mudança fica registrada no histórico público do repositório.
