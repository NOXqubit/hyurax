            Mercado de máquinas

            —

            Máquinas que outros nós anunciaram, assinadas por eles e repassadas de par em par, sem servidor. Alugar capacidade é um JOB que só manda unidades para aquela máquina: cada unidade volta e é refeita aqui antes de contar, e você assina um recibo do trabalho verificado. Preços em créditos de computação, que não são dinheiro nem HYX.

            Esta máquina no mercado

            Como o anúncio aparece para os outros

            Linhas, memória e GPU saem das métricas reais desta máquina. O benchmark é ESTIMADO: ninguém confere o que o dono declara; a reputação de cada máquina é a que o SEU nó mediu conferindo trabalho dela.

            Armazenamento distribuído

            —

            O arquivo é cifrado aqui (ChaCha20-Poly1305, chave que nunca sai deste computador), dividido em fragmentos de dados e de paridade (Reed–Solomon) e cada fragmento vai para um nó diferente. Quem guarda não vê o conteúdo. Desafios de guarda conferem, sem baixar, que cada fragmento continua lá; fragmento perdido é reconstruído e mandado para outro nó.

            Guardar um arquivo na rede

            Este nó guardando para outros

            A cota se ajusta em Mercado de máquinas → disco oferecido. Os fragmentos ficam na pasta de dados, em nuvem/guarda, cifrados por quem mandou.

            Seus arquivos na rede

            Cada quadrado é um fragmento: cheio = guardado e conferido; tracejado = enviando; hachurado = perdido (vai ser reparado). Redondo = paridade.

                Malha: como os outros nós chegam aqui

                Sem servidor central: este nó procura outros na rede local, tenta abrir a porta no roteador sozinho (UPnP) e confere com um par se é alcançável. Quem não é alcançável guarda uma vaga numa ponte (outro nó), que só repassa bytes cifrados.

                  Ajustes

                  Estimativa de energia

                  A energia não é medida: é uma estimativa pelo uso de CPU medido do programa e pelos watts por núcleo que você informar.

                  Aparência

                  Cloud Design 2.0: o escuro é o padrão; o claro serve para salas iluminadas. A escolha fica só neste computador.

                  Painel e avisos

                  API externa e contas de cliente

                  Contas de cliente mandam JOBs de outro computador por /api/v1/externa/, com a chave de acesso delas (ver docs/API-EXTERNA.md). Cada conta tem um limite de créditos de computação, que não são dinheiro nem HYX. A conexão não é cifrada: use só em rede local confiável.

                  Atualização

                  Só entra versão nova cujo manifesto foi assinado pela chave de lançamento do projeto (embutida neste programa). O instalador baixado é conferido por tamanho e SHA-512 contra o manifesto antes de abrir, e ainda mostra os termos.
