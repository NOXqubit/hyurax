    Boas-vindas ao Hyurax

    Este programa liga um nó do Hyurax neste computador e minera. Cada bloco que você achar paga uma recompensa, e ela cai na sua carteira.

    REDE DE TESTE. O HYUR minerado aqui é de teste e não tem valor.

    Para receber a recompensa, você precisa de uma carteira.
    • 0 de no mínimo 10 caracteres
    • Repita a senha no segundo campo

    A senha não é pedida para minerar, só para enviar HYUR. Anote num lugar seguro: ninguém consegue recuperá-la.

    A senha é embaralhada de propósito devagar, para ninguém adivinhar por tentativa. Em computador antigo isso leva até um minuto.

    Minerar só precisa do endereço. A senha continua sendo a mesma de quando a carteira foi criada e só é pedida para enviar HYUR.

    Carteira pronta

    Seu endereço

    Guarde a senha e uma cópia do arquivo carteira.txt. Sem os dois, o saldo se perde para sempre. Ninguém consegue recuperar.

    O trabalho desta máquina

    parado

    Minerar no Hyurax não é só embaralhar números: cada bloco carrega uma conta grande que a rede inteira confere. Hoje essa conta é multiplicação de matrizes, o cálculo que está por baixo de simulação, engenharia e treino de inteligência artificial.

    Quem confere não refaz a conta: três sorteios bastam para pegar qualquer resultado errado, e custam quase nada. É por isso que a rede aceita trabalho pesado sem cada nó repetir o trabalho.

    O que ainda não é. As contas de hoje são geradas pelo próprio bloco, não vêm de ninguém de fora. O próximo passo do projeto é abrir a fila para trabalho de verdade — genética, clima, engenharia — com quem precisa pagando pela conta. Enquanto isso não existe, o programa não vai dizer que existe.
